# 郑州大学医院助手

郑州大学医院助手前端项目，使用 Vue 3 + Vite 构建的智能医疗问诊系统。

## 功能特性

- 智能医疗问诊对话
- 流式响应显示
- 响应式设计，支持移动端
- 基于 Element Plus 的现代UI设计

## 开发说明

本项目使用 Vue 3 的 `<script setup>` 语法，了解更多请查看 [script setup 文档](https://v3.vuejs.org/api/sfc-script-setup.html#sfc-script-setup)。

更多 Vue IDE 支持信息请参考 [Vue 工具链指南](https://vuejs.org/guide/scaling-up/tooling.html#ide-support)。
